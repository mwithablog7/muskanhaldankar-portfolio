Drop your project images in THIS folder.

Then reference them in src/data/projects.ts like:

  images: ['images/projects/my-screenshot.png']

Tips:
- Prefer PNG screenshots or WebP/JPG photos under ~300 KB each.
- The FIRST image in the list becomes the card cover on the Work page.
- If a file is missing, the site shows a clean "Add project image" box
  instead of a broken image.
